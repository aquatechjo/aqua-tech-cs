# UI-10 — Discovery, Pricing, and Proposal Workspace Polish

Status: **implemented**

## Goal

Give the complete pre-project commercial journey one compact desktop-first visual contract without changing its governed workflow.

## Scope

- Discovery session list and guided intake.
- Versioned Discovery report review.
- Human pricing workspace and commercial line editing.
- Central Proposal workspace, review, delivery, and version history.
- Existing public Discovery conversation and Proposal decision surfaces.

## Visual contract

- One consistent page rhythm and compact action row.
- Compact 88px operational metrics with a logical accent edge.
- Better containment for long forms, evidence, commercial tables, and review panels.
- Stable readable line height for report and Proposal content.
- Responsive wrapping, logical properties, and reduced-motion coverage.

## Preserved behavior

- Discovery facts, evidence provenance, gaps, and completion rules.
- Report, pricing, and Proposal version history.
- Pricing totals, margins, tax, approval, and visibility rules.
- Proposal preparation, delivery, client response, and conversion logic.
- Tenant scope, permissions, routes, API contracts, and public-token security.

## Quality gate

- Design System synchronization check.
- Lint, typecheck, unit and closure suites.
- Production build.
- UI-10 contract assertions in the existing Design System adoption test.
