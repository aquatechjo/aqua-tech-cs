# Aqua.Tech Brand System

## Brand Position

Aqua.Tech is a growth, software, and AI company that builds digital systems, websites, automations, and operational solutions for businesses.

## Core Personality

- Technical
- Clear
- Fast
- Growth-focused
- AI-ready
- Practical
- Scalable

## Visual Direction

Aqua.Tech visual identity should feel like:

- Modern software company
- AI and automation ready
- Dark technical workspace
- Clean operating system
- Code-inspired but business-friendly

## Core Colors

### Background

- Deep Navy: #020617
- Slate Surface: #0F172A
- Soft Surface: #111827

### Brand Colors

- Aqua: #06B6D4
- Sky: #38BDF8
- Blue: #2563EB

### Text

- Main Text: #F8FAFC
- Muted Text: #94A3B8
- Soft Text: #64748B

### State Colors

- Success: #22C55E
- Warning: #F59E0B
- Danger: #EF4444

## UI Style

Use:

- Dark backgrounds
- Aqua/blue gradients
- Glass cards
- Thin white borders
- Code-inspired badges
- Subtle grid backgrounds
- Rounded cards
- Clear spacing

Avoid:

- Heavy legal-style green themes
- Random colors
- Overly colorful dashboards
- Generic SaaS templates
- Different styles between projects

## Brand Language

Use phrases like:

- From idea to launch
- Build. Launch. Grow.
- Growth • Software • AI
- Clear systems for real business growth
- Automate work. Improve operations. Launch faster.

Arabic tone:

- واضح
- عملي
- مباشر
- موجه للنمو
- بدون مبالغة

Examples:

Good:
"نبني نظامًا يساعدك تستقبل العملاء، تنظّم العمليات، وتتابع النمو من مكان واحد."

Bad:
"نقدم أفضل وأقوى وأحدث الحلول التقنية في السوق."
