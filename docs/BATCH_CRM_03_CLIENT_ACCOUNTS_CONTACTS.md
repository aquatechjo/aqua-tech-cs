# CRM-03 — Client Accounts and Contacts

## الهدف

إكمال طبقة البيانات الأساسية في المرحلة الأولى من خارطة Aqua Tech CS عبر فصل
حساب العميل عن الأشخاص الذين يتم التواصل معهم، دون إنشاء جدول شركة خارجي
يتعارض مع نموذج `Company` المستخدم أصلًا لشركة Aqua Tech نفسها.

## قرار النموذج

- يبقى `Company` هو المستأجر الداخلي المشغّل للنظام: Aqua Tech.
- يمثل `Client` حساب العميل الخارجي، سواء كان شركة أو فردًا.
- يمثل `ClientContact` الأشخاص المرتبطين بحساب العميل.
- تحفظ حقول البريد والهاتف الحالية في `Client` كملخص متوافق للجهة الرئيسية،
  بينما يكون سجل `ClientContact` هو المصدر التفصيلي لجهات الاتصال.

هذا يمنع إنشاء `Company` ثانية بمعنى مختلف، ويحافظ على توافق المشاريع والفواتير
والفرص الحالية التي ترتبط بـ`Client`.

## النطاق المنفذ

- إضافة نموذج `ClientContact` مرتبط بالشركة الداخلية والعميل.
- دعم الاسم والمسمى والقسم والبريد والهاتف وواتساب والملاحظات.
- دعم جهة رئيسية واحدة فقط لكل عميل.
- دعم تمييز صاحب القرار.
- إضافة أرشفة واستعادة دون حذف التاريخ.
- مزامنة بريد وهاتف العميل مع الجهة الرئيسية فقط.
- اختيار بديل نشط بصورة منضبطة عند أرشفة الجهة الرئيسية.
- ترحيل بيانات البريد والهاتف الحالية إلى جهة رئيسية للسجلات القديمة.
- إنشاء جهة رئيسية تلقائيًا عند تحويل عميل جديد، أو حفظ الشخص كجهة إضافية
  عندما يكون العميل موجودًا ولديه جهة رئيسية مختلفة.
- توسيع إنشاء العميل اليدوي لإنشاء جهة رئيسية عند توفر بيانات التواصل.
- إضافة ملف عميل مستقل في `/dashboard/clients/[id]`.
- إضافة واجهة عرض وإنشاء وتعديل وتعيين رئيسية وأرشفة واستعادة جهات الاتصال.
- إضافة صلاحية قراءة مستقلة للعملاء، مع إبقاء التعديل ضمن صلاحيات إدارة
  العملاء.
- إضافة أحداث Audit مخصصة لكل تغييرات جهات الاتصال.

## ضوابط الأمان والمنطق

1. كل استعلام وتعديل مقيد بـ`companyId` للمستخدم المصادق.
2. لا يمكن أن توجد أكثر من جهة رئيسية نشطة للعميل نفسه.
3. العمليات التي تغير الجهة الرئيسية أو تؤرشف جهة تستخدم Transaction وقفل
   للسجل.
4. لا تُحذف جهة الاتصال فعليًا؛ تستخدم الأرشفة للحفاظ على التاريخ.
5. لا يملك `MEMBER` العام صفحة العملاء كاملة؛ تبقى القراءة لأدوار الإدارة
   والمبيعات والعمليات والمالية.
6. لا تُدمج جهات الاتصال تلقائيًا، ويُمنع إنشاء نفس الاسم مع وسيلة التواصل
   نفسها داخل حساب العميل.

## الترحيل

`20260729213000_crm_03_client_contacts`

الترحيل إضافي ولا يحذف بيانات. ينشئ جهة رئيسية لكل عميل قديم لديه بريد أو
هاتف، مستخدمًا الاسم الحالي كقيمة انتقالية لأن النظام السابق لم يكن يحفظ اسم
الشخص بصورة منفصلة. يمكن للفريق تصحيح الاسم من ملف العميل.
